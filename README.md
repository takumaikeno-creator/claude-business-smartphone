# SumaGig (スマギグ) — スマホで完結するマイクロジョブ・プラットフォーム

> **ミッション**: スマートフォン1台で、仕事を受注・納品・報酬受取まで完結できる日本最大のモバイルファーストマーケットプレイスを構築する

---

## What is SumaGig?

SumaGigは、**スマホだけで稼げる**マイクロジョブプラットフォームです。

- **出品者（ワーカー）**: 自分のスキルをスマホで登録 → 受注 → 納品 → 即時報酬受取
- **発注者（クライアント）**: スマホで案件掲載 → マッチング → 成果物受取 → 評価

従来のクラウドソーシングはPCでの作業が前提でした。SumaGigはモバイルUXを徹底的に再設計し、**スキマ時間の収益化**を実現します。

---

## ビジネスモデル概要

| 収益源 | 単価 | 対象 |
|--------|------|------|
| プラットフォーム手数料 | 取引額の15% | 全ユーザー |
| プレミアム会員（ワーカー） | ¥1,480/月 | 上位表示・優先マッチング |
| プレミアム会員（クライアント） | ¥2,980/月 | 無制限掲載・AIマッチング |
| AI副業アシスタント | ¥980/月 | 提案文・プロフィール自動生成 |

**目標**: 月次黒字転換 6ヶ月以内 / 年間GMV ¥100M 達成 12ヶ月以内

## ターゲットユーザー

### ワーカー側
- 隙間時間で稼ぎたい主婦・学生・副業サラリーマン
- スマホネイティブ世代（20〜35歳）
- SNS・動画編集・翻訳・データ入力スキル保有者

### クライアント側
- 中小企業のSNS運用担当者
- 個人事業主・フリーランサー
- EC事業者（商品説明文、画像編集など）

---

## スマホ完結の5つのカテゴリ

1. **コンテンツ制作** — SNS投稿文、ブログ記事、動画台本
2. **画像・動画編集** — サムネイル、リール編集、バナー作成
3. **データ・リサーチ** — 競合調査、データ入力、口コミ収集
4. **翻訳・文字起こし** — 日英翻訳、音声文字起こし
5. **AIプロンプト代行** — 画像生成、文章生成の代行
