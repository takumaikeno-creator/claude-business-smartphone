# ユーザーインタビュースクリプト

**目的**: プロダクトローンチ前の仮説検証  
**対象**: ワーカー候補（副業志望者）/ クライアント候補（発注者）  
**時間**: 30〜40分 / 人  
**実施方法**: Zoom（スマホからの参加を推奨）  
**目標人数**: 月5人以上（PMが毎週水曜に実施）

---

## インタビュー前の準備

- [ ] 録音許可を事前に取得
- [ ] Notionにメモシートを用意
- [ ] スマホ画面共有をリクエストできるよう準備
- [ ] 謝礼: Amazonギフト券¥1,000

---

## ワーカー向けスクリプト

### 0. アイスブレイク（3分）

```
「今日はお時間いただきありがとうございます。
30〜40分のインタビューなのですが、
私たちがサービスを作る立場なので、
正直に感じたことを教えていただけると嬉しいです。
答えに正解・不正解はありません。
お名前を伺ってもよいですか？普段はどんなお仕事をされていますか？」
```

### 1. 現状の副業・収入事情（8分）

```
Q1. 今、副業や本業以外で収入を得ていますか？もしあれば教えてください。

Q2. （副業をしている場合）どんな方法で稼いでいますか？

Q3. 副業を始めたきっかけはなんですか？

Q4. 副業活動は主にスマホとPCどちらでしていますか？
    → スマホの場合: どのアプリで？不便に感じることはありますか？
    → PCの場合: スマホでできたらいいなと思うことはありますか？

Q5. 1週間に副業に使える時間はどれくらいですか？
    どの時間帯が多いですか？（通勤中、昼休み、育児の合間など）
```

**観察ポイント**: スキマ時間の使い方・スマホ依存度・現在の不満点

---

### 2. 既存サービスへの不満（7分）

```
Q6. クラウドワークス・ランサーズ・ランサーバなど使ったことはありますか？
    → あり: どんな経験でしたか？何が不満でしたか？
    → なし: なぜ使わなかったと思いますか？

Q7. （使ったことがある場合）スマホでの使いやすさはいかがでしたか？
    スマホで完結しましたか？PCを使う必要がありましたか？

Q8. 一番困った体験を教えてください。
    「もっとこうだったらよかった」と思ったことはありますか？
```

---

### 3. 仮説の検証（10分）

```
Q9. 「スマホだけで仕事を受注して、納品して、お金を受け取れるサービス」
    があったとしたら、使いたいと思いますか？

Q10. どんなカテゴリの仕事なら、スマホだけで完結できると思いますか？
     （例: SNS投稿文、画像編集、データ入力、翻訳、AIプロンプト作成）

Q11. 「月に1〜2案件受注できれば十分」という方と
     「毎日稼ぎたい」という方、どちらに近いですか？

Q12. もし今すぐ使えるとしたら、まず試してみたいカテゴリはどれですか？
     その理由は？

Q13. 月¥1,480のプレミアム会員（検索上位表示・AI提案文生成・応募無制限）
     があるとしたら、使いますか？使わないとしたら、なぜですか？
```

---

### 4. プロトタイプ反応（7分）※ LP を見せながら

```
「SumaGigというサービスのLPをお見せしますね。
スマホで見ていただけますか？
見ながら思ったことを声に出して教えてください。」

観察ポイント:
- どこで止まるか・読むか飛ばすか
- 登録ボタンまで自然に辿り着けるか
- 料金表を見た時の反応
- ユーザーの声（テスティモニアル）への反応

Q14. このサービスを一言で表すとどんなサービスですか？
     （理解度チェック）

Q15. 登録する気になりますか？何か不安はありますか？
```

---

### 5. クロージング（5分）

```
Q16. 最後に、このサービスに一番期待することを教えてください。

Q17. 友達や知人に紹介するとしたら、どんな人に紹介しますか？
     どんな言葉で紹介しますか？

「今日は貴重なお話をありがとうございました。
正式ローンチ時に優先案内させていただきます。
メールアドレスを登録しておきますね。」
```

## クライアント向けスクリプト

### 1. 現状の外注事情（8分）

```
Q1. 現在、外部に業務を委託していますか？どんな業務ですか？

Q2. 外注先をどうやって見つけていますか？（クラウドソーシング・知人紹介・SNS等）

Q3. 外注管理はスマホとPCどちらがメインですか？
    スマホで完結したら便利だと思いますか？

Q4. 今の外注で一番困っていることは何ですか？
    （品質・コミュニケーション・スピード・コスト等）
```

### 2. 価格感度（5分）

```
Q5. 外注に使っている月間の予算はどれくらいですか？

Q6. 手数料15%というのは許容できますか？今使っているサービスの手数料は知っていますか？

Q7. 月¥2,980のプレミアム会員（AI自動マッチング・無制限掲載・専任CS）
    があるとしたら使いますか？
```

### 3. 仮説検証（10分）

```
Q8. SNS投稿文や画像編集、リサーチ業務をスマホで完結して外注できたら
    どんな変化がありますか？

Q9. 信頼できるワーカーを見つけるために、何が一番大切ですか？
    （評価数・ポートフォリオ・バッジ・レスポンス速度等）

Q10. 理想の外注フローを教えてください。
     今はどこが一番面倒ですか？
```

## インタビュー獲得方法

**ワーカー候補**:
1. X（Twitter）で「#副業 スマホ」タグ検索 → DM
2. Wantedlyのフォロワーにメッセージ
3. 自社SNSで「副業に興味ある方、30分お話させてください」投稿
4. 知人のネットワーク経由

**クライアント候補**:
1. SNS運用代行を探しているスモールビジネス
2. Twitterで「SNS 外注 困ってる」検索
3. 地元の経営者ネットワーク・商工会

**目標**: 毎週2〜3人実施 → 月10人のインサイトを蓄積
